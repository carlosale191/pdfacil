# Objetivo
Construir uma aplicação desktop, executada e utilizada via CLI que faz edição em arquivos pdf. Nome: PDFácil

# Contexto
- Quem é você: um engenheiro de software sênior. Explique sempre o que está fazendo, e por quê, sempre em português brasileiro, de forma curta e objetiva.

## Requisitos funcionais
- Quando aplicação for inicializada um menu com as opções de edição será exibido. O usuário deverá digitar o número relacionado a opção.
- Opções de: dividir pdf selecionando intervalo, comprimir tamanho de pdf, converter docx para pdf, juntar pdf.
- Após selecionar opção, abrir possibilidade para selecionar arquivo a ser manipulado.
- Opção de sair/finalizar aplicação.

## Requisitos não-funcionais
- Todas funções devem estar dentro de try-catch, capturando erros gerados e informando qual tipo de erro.
- Enquanto o processo é feito informar ao usuário e gerar barra de progresso. Informar quando terminou e em qual pasta está.
- Ao fim de cada processo voltar ao menu principal.

# Stack
- Python 3.11 com bibliotecas (gratuitas) que forem necessárias, como a pypdf, pdftool, etc.
